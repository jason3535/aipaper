Long Short-Term Memory

摘要 · Abstract

通过循环反向传播学习跨长时间间隔存储信息需要很长时间，主要是因为误差反向流动不足且衰减。我们简要回顾了Hochreiter(1991)对这一问题的分析，然后通过引入一种新颖、高效的基于梯度的方法——长短期记忆(LSTM)来解决它。通过在不会造成损害的地方截断梯度，LSTM可以通过在特殊单元内强制恒定误差流经恒定误差轮盘，学习跨越超过1000个离散时间步的最小时间滞后。乘法门控单元学习打开和关闭对恒定误差流的访问。LSTM在空间和时间上是局部的；每个时间步和权重的计算复杂度为O(1)。我们对人工数据的实验涉及局部、分布式、实值和带噪声的模式表示。与实时循环学习、随时间反向传播、循环级联相关、Elman网络和神经序列分块相比，LSTM导致了更多成功的运行，并且学习速度更快。LSTM还解决了以前循环网络算法从未解决过的复杂、人工长时滞任务。1 引言 原则上，循环网络可以利用其反馈连接以激活的形式存储近期输入事件的表示（短期记忆，与由缓慢变化的权重视为长期记忆相对）。这对于许多应用具有潜在重要意义，包括语音处理、非马尔可夫控制和音乐创作（Mozer, 1992）。然而，最广泛使用的用于学习在短期记忆中存储什么内容的算法要么耗时过多，要么根本表现不佳，特别是当输入和相应教师信号之间的最小时间滞后较长时。尽管理论上有趣，但现有方法并未提供比具有有限时间窗口的前馈网络中的反向传播更明显的实际优势。本文回顾了对该问题的分析，并提出了补救措施。 问题。使用传统的随时间反向传播（BPTT；Williams & Zipser, 1992; Werbos, 1988）或实时循环学习（RTRL；Robinson & Fallside, 1987），沿时间反向流动的误差信号往往会(1)爆炸或(2)消失；反向传播误差的时间演化指数地依赖于权重的大小（Hochreiter, 1991）。情况1可能导致权重振荡；情况2中，学习跨越长时滞需要令人望而却步的时间，或者根本不起作用（见第3节）。本文介绍了长短期记忆（LSTM），一种新颖的循环网络架构，结合了适当的基于梯度的学习算法。LSTM旨在克服这些误差反向流动问题。它能够学习跨越超过1000步的时间间隔，即使是在有噪声、不可压缩的输入序列情况下，也不会损失短时滞能力。这是通过一种高效的基于梯度的算法实现的，该算法强制恒定（因此既不会爆炸也不会消失）的误差流经特殊单元的内部状态（前提是在某些架构特定点截断梯度计算；但这不会影响长期误差流）。第2节简要回顾了先前的工作。第3节从概述Hochreiter(1991)对消失误差的详细分析开始。然后介绍了一种用于教学目的的朴素恒定误差反向传播方法，并强调了其在信息存储和检索方面的问题。这些问题导致了第4节中描述的LSTM架构。第5节展示了大量实验以及与竞争方法的比较。LSTM优于它们，并且学会了解决其他

Learning to store information over extended time intervals by recurrent backpropagation takes a very long time, mostly because of insufficient, decaying error backflow. We briefly review Hochreiter’s (1991) analysis of this problem, then address it by introducing a novel, efficient, gradient-based method called long short-term memory (LSTM). Truncating the gradient where this does not do harm, LSTM can learn to bridge minimal time lags in excess of 1000 discrete-time steps by enforcing constant error flow through constant error carousels within special units. Multiplicative gate units learn to open and close access to the constant error flow. LSTM is local in space and time; its computational complexity per time step and weight is O(1). Our experiments with artificial data involve local, distributed, real-valued, and noisy pattern representations. In compar-isons with real-time recurrent learning, back propagation through time, recurrent cascade correlation, Elman nets, and neural sequence chunk-ing, LSTM leads to many more successful runs, and learns much faster. LSTM also solves complex, artificial long-time-lag tasks that have never been solved by previous recurrent network algo

核心贡献 · Key contributions

  • 提出具有恒定误差轮盘（CEC）的LSTM，解决梯度消失问题，可学习超过1000时间步的长时滞。
    Introduces LSTM with constant error carousels to solve vanishing gradient problem, enabling learning over 1000 time steps.
  • 乘法门单元（输入门和输出门）控制信息流动，解决输入和输出权重冲突。
    Multiplicative gate units (input and output gates) control information flow, resolving input and output weight conflicts.
  • 记忆细胞块共享门控，提高存储效率并略微减少参数。
    Memory cell blocks share gates, improving storage efficiency and slightly reducing parameters.
  • 每时间步计算复杂度为O(W)，空间和时间局部性优于完全BPTT。
    O(W) per time step computational complexity, local in space and time, unlike full BPTT.
  • 在长时滞任务上优于RTRL、BPTT等方法，包括噪声和分布式表示场景。
    Outperforms RTRL, BPTT, and other methods on long-time-lag tasks, including noisy and distributed representations.
  • 实验表明随时间滞长度扩展良好，学习时间仅适度增加。
    Empirically scales well with time lag length, requiring only modest increase in learning time.

局限 · Limitations

  • 内部状态漂移可能导致梯度消失，需谨慎初始化输入门偏置。
    Internal state drift may cause gradient vanishing if inputs are biased; requires careful initialization of input gate bias.
  • 对于短时滞的简单任务，随机权重猜测可能比LSTM更快。
    For simple tasks with short time lags, random weight guessing can be faster than LSTM.
  • 门结构增加参数数量，门控失效时可能阻碍学习。
    Gate structure increases parameter count and may hinder learning when gates fail to open/close appropriately.
  • 截断梯度在细胞边界中断反向传播，可能限制特定连接的误差流动。
    Truncated gradient breaks backpropagation at cell boundaries, potentially limiting error flow to certain connections.
  • 未针对超过1000步的极长序列设计；极端滞后的性能可能下降。
    Not designed for very long sequences beyond 1000 steps; performance may degrade with extreme lags.
