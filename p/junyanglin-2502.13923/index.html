摘要 · Abstract

我们推出了Qwen2.5-VL，这是Qwen视觉语言系列的最新旗舰模型，在基础能力和创新功能方面均取得了显著进展。Qwen2.5-VL通过增强的视觉识别、精确的物体定位、稳健的文档解析和长视频理解，在理解和交互世界方面实现了重大飞跃。其一个突出特点是能够使用边界框或点精确地定位物体。它能够从发票、表单和表格中提取稳健的结构化数据，并对图表、示意图和布局进行详细分析。为了处理复杂输入，Qwen2.5-VL引入了动态分辨率处理和绝对时间编码，使其能够处理不同尺寸的图像和长达数小时的视频，并实现秒级事件定位。这使得模型能够原生感知空间尺度和时间动态，而无需依赖传统的归一化技术。通过从头训练原生动态分辨率的视觉Transformer（ViT）并结合窗口注意力机制，我们在保持原生分辨率的同时降低了计算开销。因此，Qwen2.5-VL不仅在静态图像和文档理解方面表现出色，还能作为交互式视觉代理，在真实场景中执行推理、工具使用和任务执行，例如操作计算机和移动设备。Qwen2.5-VL提供三种尺寸，满足从边缘AI到高性能计算的不同应用场景。旗舰版Qwen2.5-VL-72B模型与GPT-4o和Claude 3.5 Sonnet等最先进模型相媲美，尤其在文档和图表理解方面表现卓越。此外，Qwen2.5-VL保持了强大的语言性能，保留了Qwen2.5大语言模型的核心语言能力。

We introduce Qwen2.5-VL, the latest flagship model of Qwen vision-language series, which demonstrates significant advancements in both foundational capabilities and innovative functionalities. Qwen2.5-VL achieves a major leap forward in understanding and interacting with the world through enhanced visual recognition, precise object localization, robust document parsing, and long-video comprehension. A standout feature of Qwen2.5-VL is its ability to localize objects using bounding boxes or points accurately. It provides robust structured data extraction from invoices, forms, and tables, as well as detailed analysis of charts, diagrams, and layouts. To handle complex inputs, Qwen2.5-VL introduces dynamic resolution processing and absolute time encoding, enabling it to process images of varying sizes and videos of extended durations (up to hours) with second-level event localization. This allows the model to natively perceive spatial scales and temporal dynamics without relying on traditional normalization techniques. By training a native dynamic-resolution Vision Transformer (ViT) from scratch and incorporating Window Attention, we reduce computational overhead while maintaining native resolution. As a result, Qwen2.5-VL excels not only in static image and document understanding but also as an interactive visual agent capable of reasoning, tool usage, and task execution in real-world scenarios such as operating computers and mobile devices. Qwen2.5-VL is available in three sizes, addressing diverse use cases from edge AI to high-performance computing. The flagship Qwen2.5-VL-72B model matches state-of-the-art models like GPT-4o and Claude 3.5 Sonnet, particularly excelling in document and diagram understanding. Additionally, Qwen2.5-VL maintains robust linguistic performance, preserving the core language competencies of the Qwen2.5 LLM.

核心贡献 · Key contributions

  • 提出原生动态分辨率ViT和窗口注意力机制，降低算力开销同时保持原生分辨率。
    Proposes native dynamic-resolution ViT with window attention, reducing compute while preserving native resolution.
  • 引入绝对时间对齐的MRoPE，实现小时级视频中秒级事件定位。
    Introduces absolute-time-aligned MRoPE for video, enabling second-level event localization in hour-long videos.
  • 将预训练数据从1.2万亿token扩展到4.1万亿，多阶段训练提升多模态能力。
    Scales pre-training data from 1.2T to 4.1T tokens with multi-stage training, boosting multimodal capabilities.
  • 在文档解析、目标定位和视频理解上达到顶尖水平，与GPT-4o和Claude 3.5 Sonnet持平。
    Achieves state-of-the-art in document parsing, object grounding, and video understanding, matching GPT-4o and Claude 3.5 Sonnet.
  • 提供3B、7B、72B三种尺寸，兼顾边缘AI和高性能任务，小模型表现优异。
    Offers three model sizes (3B, 7B, 72B), balancing edge AI and high-performance tasks with strong small-model results.
  • 保持源自Qwen2.5 LLM的纯文本语言能力，避免多模态退化。
    Maintains robust pure-text language performance inherited from Qwen2.5 LLM, avoiding multimodal degradation.

局限 · Limitations

  • 窗口注意力可能限制超大图像或复杂场景的全局上下文捕获。
    Window attention may limit global context capture for very large images or complex scenes.
  • 绝对时间编码假设FPS一致，实际中可变FPS视频可能降低时间精度。
    Absolute time encoding assumes consistent FPS; real-world variable FPS videos may degrade temporal accuracy.
  • 大规模预训练和72B模型需要大量算力，限制了可复现性和部署。
    Large-scale pre-training and 72B model require substantial compute, limiting reproducibility and deployment.
  • 智能体能力在受控基准上展示，对开放真实世界任务的泛化性验证不足。
    Agent capabilities are demonstrated on controlled benchmarks; generalization to truly open-ended real-world tasks is less validated.
  • 尽管OCR整体强大，文档解析可能在高度风格化或退化手写文本上仍有困难。
    Document parsing may struggle with highly stylized or degraded handwritten text despite strong overall OCR.
