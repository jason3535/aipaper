Q-Transformer：通过自回归 Q 函数进行可扩展的离线强化学习

Q-Transformer: Scalable Offline Reinforcement Learning via Autoregressive Q-Functions

摘要 · Abstract

在这项工作中，我们提出了一种可扩展的强化学习方法，用于从大型离线数据集中训练多任务策略，该方法可以利用人类演示和自主收集的数据。我们的方法使用 Transformer 为通过离线时间差分备份训练的 Q 函数提供可扩展的表示，因此我们将该方法称为 Q-Transformer。通过将每个动作维度离散化并将每个动作维度的 Q 值表示为单独的标记，我们可以应用有效的高容量序列建模技术进行 Q 学习。我们提出了几个设计决策，以实现良好的离线 RL 训练性能，并表明 Q-Transformer 在大型多样化的真实世界机器人操作任务套件上优于先前的离线 RL 算法和模仿学习技术。项目和视频可在 https://qtransformer.github.io 找到。

In this work, we present a scalable reinforcement learning method for training multi-task policies from large offline datasets that can leverage both human demonstrations and autonomously collected data. Our method uses a Transformer to provide a scalable representation for Q-functions trained via offline temporal difference backups. We therefore refer to the method as Q-Transformer. By discretizing each action dimension and representing the Q-value of each action dimension as separate tokens, we can apply effective high-capacity sequence modeling techniques for Q-learning. We present several design decisions that enable good performance with offline RL training, and show that Q-Transformer outperforms prior offline RL algorithms and imitation learning techniques on a large diverse real-world robotic manipulation task suite. The project's website and videos can be found at https://qtransformer.github.io

核心贡献 · Key contributions

  • 提出了 Q-Transformer，一种可扩展的离线强化学习方法，通过逐维度动作离散化，使用 Transformer 表示 Q 函数。
    Proposes Q-Transformer, a scalable offline RL method using Transformer for Q-functions via per-dimension action discretization.
  • 引入了一种保守正则化器，将分布外动作的 Q 值正则化到最小可能奖励，从而改进离线学习。
    Introduces a conservative regularizer that regularizes Q-values of out-of-distribution actions to the minimal possible reward, improving offline learning.
  • 将蒙特卡洛和 n 步回报与时间差分备份相结合，加速学习并提升性能。
    Combines Monte Carlo and n-step returns with temporal difference backups to accelerate learning and improve performance.
  • 在大规模真实世界机器人操作任务上，展示了优于先前离线强化学习和模仿学习方法的性能。
    Demonstrates superior performance over prior offline RL and imitation learning methods on large-scale real-world robotic manipulation tasks.
  • 展示了在极大数据集（30 万次试验）上的可扩展性，性能持续优于基线。
    Shows scalability to extremely large datasets (300k trials) with continued performance improvement over baselines.

局限 · Limitations

  • 仅限于稀疏二元奖励任务（成功/失败），并非适用于所有强化学习问题。
    Limited to sparse binary reward tasks (success/failure), not universal for all RL problems.
  • 逐维度离散化在高维动作空间中可能变得繁琐，增加序列长度和推理时间。
    Per-dimension discretization may become cumbersome for high-dimensional action spaces, increasing sequence length and inference time.
  • 均匀动作离散化可能无法很好地处理需要粗粒度和细粒度运动的任务。
    Uniform action discretization may not handle tasks requiring both coarse and fine movement granularities well.
  • 专注于离线强化学习；扩展到在线微调留待未来工作。
    Focuses on offline RL; extending to online fine-tuning is left for future work.
