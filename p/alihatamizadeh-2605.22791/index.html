摘要 · Abstract

线性注意力用固定大小的循环状态替代了 softmax 注意力的无限缓存，将序列混合降至线性时间，解码内存恒定。难点不仅在于遗忘什么，更在于如何编辑压缩记忆而不扰乱已有关联。Delta 规则模型在写入新值前减去当前读取，Kimi Delta 注意力（KDA）通过通道级衰减增强遗忘。但活跃编辑仍使用单一标量门控制两件事：键侧擦除多少旧内容，值侧提交多少新内容。我们提出 Gated DeltaNet-2，它继承了自适应遗忘和通道级衰减，同时解决了擦除与写入之间的标量耦合问题。Gated Delta Rule-2 通过通道级擦除门 b_t 和写入门 w_t 分离这两个角色，当两门退化为同一标量时简化为 KDA，当衰减也退化时简化为 Gated DeltaNet。我们推导了快速权重更新视角、将通道级衰减吸收为非对称擦除因子的分块 WY 算法，以及保持高效并行训练的门感知反向传播。在 1.3B 参数、100B FineWeb-Edu token 训练下，Gated DeltaNet-2 在语言建模、常识推理和检索任务中，整体结果优于 Mamba-2、Gated DeltaNet、KDA 和 Mamba-3 变体。其优势在长上下文 RULER 针包基准测试中最为显著，改进了多键检索设置，并在循环和混合设置中均保持强劲性能。代码见 https://github.com/NVlabs/GatedDeltaNet-2。

Linear attention replaces the unbounded cache of softmax attention with a fixed-size recurrent state, reducing sequence mixing to linear time and decoding to constant memory. The hard part is not just what to forget, but how to edit this compressed memory without scrambling existing associations. Delta-rule models subtract the current read before writing a new value, and Kimi Delta Attention (KDA) sharpens forgetting with channel-wise decay. But the active edit still uses a single scalar gate to control two different things: how much old content to erase on the key side and how much new content to commit on the value side. We introduce Gated DeltaNet-2, which generalizes both Gated DeltaNet and KDA by inheriting adaptive forgetting and channel-wise decay while addressing their shared limitation, the scalar tie between erasing and writing. Gated Delta Rule-2 separates these roles with a channel-wise erase gate b_t and a channel-wise write gate w_t, reducing to KDA when both gates collapse to the same scalar and to Gated DeltaNet when the decay also collapses. We derive a fast-weight update view, a chunkwise WY algorithm with channel-wise decay absorbed into asymmetric erase factors, and a gate-aware backward pass that preserves efficient parallel training. At 1.3B parameters trained on 100B FineWeb-Edu tokens, Gated DeltaNet-2 achieves the strongest overall results among Mamba-2, Gated DeltaNet, KDA, and Mamba-3 variants across language modeling, commonsense reasoning, and retrieval. Its advantage is most pronounced on long-context RULER needle-in-a-haystack benchmarks, where it improves the evaluated multi-key retrieval setting and remains strong in both recurrent and hybrid settings. Code is available at https://github.com/NVlabs/GatedDeltaNet-2.

1 引言 1 Introduction

Transformer 架构已成为大语言模型的主导骨干，因为自注意力使每个 token 能直接访问其历史，并自然地映射到现代加速器上的并行训练。然而，其成本仍随序列长度二次增长。这一成本成为长上下文训练和高吞吐量推理的主要障碍，此时模型必须反复处理比单个注意力头维度长得多的历史。

The Transformer architecture has become the dominant backbone for large language models because self-attention gives each token direct access to its history and maps naturally to parallel training on modern accelerators. Its cost, however, still grows quadratically with sequence length. This cost becomes a central obstacle for long-context training and high-throughput inference, where the model must repeatedly process histories that are much longer than the dimension of a single attention head.

线性循环注意力走了一条不同的路。它用固定大小的循环状态替换显式注意力矩阵，将序列混合转化为线性时间循环，其内存不随上下文长度增长[1]。其吸引力显而易见，但约束也同样明显。状态是一个压缩的键值记忆，长上下文迫使许多关联共享同一有限空间，使得精确检索变得困难[2, 3, 4, 5, 6, 7]。近期工作通过赋予循环更多对持久性的控制改进了这一记忆。Mamba-2 使用数据依赖的衰减来调节记忆范围[8]。DeltaNet 用 delta 规则替代加法写入，实现对当前键所寻址关联的针对性覆盖[9, 2, 10]。Gated DeltaNet 结合 delta 规则与学习到的衰减门，赋予状态全局遗忘和针对性编辑能力[11]。Kimi Delta Attention (KDA) 通过键维度上的通道级遗忘细化了衰减侧[12]。同时，Mamba-3 通过指数梯形离散化、复值状态转移以及多输入多输出公式，推进了状态空间路线，以实现更强更高效的循环[13]。这些进展推动了循环线性模型向前发展，同时使 delta 规则记忆中的剩余瓶颈更加明显：主动编辑仍使用一个标量门控来控制擦除旧内容和写入新内容。

Linear recurrent attention takes a different path. It replaces the explicit attention matrix with a fixed-size recurrent state, turning sequence mixing into a linear-time recurrence whose memory does not grow with context length [1]. The appeal is clear, but so is the constraint. The state is a compressed key-value memory, and long contexts force many associations to share the same finite space, making exact retrieval difficult [2, 3, 4, 5, 6, 7]. Recent work has improved this memory by giving the recurrence more control over what persists. Mamba-2 uses data-dependent decay to regulate the memory horizon [8]. DeltaNet replaces additive writes with the delta rule, enabling targeted overwrite of the association addressed by the current key [9, 2, 10]. Gated DeltaNet combines the delta rule with a learned decay gate, giving the state both global forgetting and targeted editing [11]. Kimi Delta Attention (KDA) refines the decay side with channel-wise forgetting over the key dimension [12]. In parallel, Mamba-3 advances the state-space route through exponential-trapezoidal discretization, complex-valued state transitions, and a multi-input, multi-output formulation for stronger and more efficient recurrence [13]. These advances have pushed recurrent linear models forward, while making the remaining bottleneck in delta-rule memory more visible. The active edit still uses one scalar gate to control both erasing old content and writing new content.

我们提出 Gated DeltaNet-2，一种在 delta 规则中解耦擦除和写入的循环注意力层。标量绑定是一种建模限制，因为擦除和写入作用于状态的不同轴。擦除是键侧操作，决定旧读取的哪些坐标应被移除；而写入是值侧操作，决定传入值的哪些坐标应被提交。Gated DeltaNet-2 保留了 KDA 的通道级衰减，但将绑定的标量 delta 门替换为键轴上的通道级擦除门和值轴上的通道级写入门。模型可以通过衰减清除广泛上下文，通过擦除移除选定的过时关联，并通过写入仅插入应持久化的值通道。当擦除门和写入门绑定到同一标量时，Gated DeltaNet-2 恢复为 KDA。如果衰减也绑定到标量，则恢复为 Gated DeltaNet。

We propose Gated DeltaNet-2, a recurrent attention layer that decouples erase and write in the delta rule. The scalar tie is a modeling restriction because erasing and writing act on different axes of the state. Erasing is a key-side operation that decides which coordinates of the old read should be removed, while writing is a value-side operation that decides which coordinates of the incoming value should be committed. Gated DeltaNet-2 preserves KDA’s channel-wise decay, but replaces the tied scalar delta gate with a channel-wise erase gate on the key axis and a channel-wise write gate on the value axis. The model can clear broad context through decay, remove selected stale associations through erase, and insert only the value channels that should persist through write. When the erase and write gates are tied to the same scalar, Gated DeltaNet-2 recovers KDA. If the decay is tied to a scalar as well, it recovers Gated DeltaNet.

这一改变保留了高效训练路径。通过将累积的通道级衰减吸收到秩一擦除因子中，循环可采用紧凑的 WY 形式，其高层分块结构与高效 delta 规则内核使用的结构相同[14, 15, 16, 17]。正文给出建模方程和分块算法。内核级细节见补充材料。

This change preserves the efficient training path. By absorbing cumulative channel-wise decay into the rank-one erase factors, the recurrence admits a compact WY form with the same high-level chunkwise structure used by efficient delta-rule kernels [14, 15, 16, 17]. 5 相关工作 5 Related Work

高效序列模型用循环或线性时间令牌混合器替代二次自注意力，这些混合器维护固定大小的状态。早期结构化状态空间和循环模型主要使用数据无关的转移 [38, 39, 40, 16]，而 Mamba 和 Mamba-2 引入了数据依赖的选择性动力学和 SSD 框架 [41, 8]。门控线性注意力和相关线性 RNN 通过学习衰减门进一步改进了记忆控制 [17, 42]。Delta 规则模型采用互补的快权重视角，其中循环状态通过先修正当前读取再写入新值来更新，改进了 Hebbian 式累积的联想记忆 [43, 44, 45, 10]。门控 DeltaNet 为此更新添加了自适应遗忘 [11]，KDA 通过通道级衰减和高效分块算法增强了它，但仍使用标量 βt\beta_{t} 控制擦除和写入 [12]。Mamba-3 则推进了 SSM 路线，使用指数梯形离散化、通过数据依赖旋转实现的复值转移，以及 MIMO 公式，以高效解码延迟实现更强建模 [13]。我们的工作与这些方向互补。门控 DeltaNet-2 保留了 GDN 和 KDA 的 delta 规则快权重结构，但将绑定的标量更新强度替换为通道级擦除门 𝒃t{\bm{b}}_{t} 和通道级写入门 𝐰t\mathbf{w}_{t}。当两个门绑定到同一标量时，它恢复为 KDA，同时允许旧内容和新值沿不同通道模式被控制。

Efficient sequence models replace quadratic self-attention with recurrent or linear-time token mixers that maintain a fixed-size state. Early structured state-space and recurrent models used mostly data-independent transitions [38, 39, 40, 16], while Mamba and Mamba-2 introduced data-dependent selective dynamics and the SSD framework [41, 8]. Gated linear attention and related linear RNNs further improve memory control with learned decay gates [17, 42]. Delta-rule models take a complementary fast-weight view, where the recurrent state is updated by correcting the current read before writing the new value, improving associative memory over Hebbian-style accumulation [43, 44, 45, 10]. Gated DeltaNet adds adaptive forgetting to this update [11], and KDA strengthens it with channel-wise decay and an efficient chunkwise algorithm, but still uses a scalar βt\beta_{t} to control both erasing and writing [12]. Mamba-3 advances the SSM line instead, using exponential-trapezoidal discretization, complex-valued transitions implemented through data-dependent rotations, and a MIMO formulation for stronger modeling at efficient decoding latency [13]. Our work is complementary to these directions. Gated DeltaNet-2 keeps the delta-rule fast-weight structure of GDN and KDA, but replaces the tied scalar update strength with a channel-wise erase gate 𝒃t{\bm{b}}_{t} and a channel-wise write gate 𝐰t\mathbf{w}_{t}. This recovers KDA when both gates are tied to the same scalar, while allowing old content and new values to be controlled along different channel patterns.

6 结论 6 Conclusion

我们引入了门控 DeltaNet-2，一种 delta 规则循环注意力层，将主动记忆编辑解耦为通道级擦除和写入决策。擦除门 𝒃t{\bm{b}}_{t} 选择衰减状态的哪些键侧坐标被读取和移除，而写入门 𝐰t\mathbf{w}_{t} 选择哪些值侧坐标被提交。这消除了门控 DeltaNet 和 KDA 中的标量 βt\beta_{t} 绑定，将两者恢复为特例，并通过 WY 形式和门感知内核保持了高效的分块训练。在匹配的 1.3B 训练下，门控 DeltaNet-2 在语言建模、常识推理、合成检索和真实世界召回方面改进了循环和混合前沿，同时仅增加了少量恒定吞吐量开销。消融实验表明两个门都有贡献，其中擦除门贡献了大部分增益。

We introduced Gated DeltaNet-2, a delta-rule recurrent attention layer that decouples the active memory edit into channel-wise erase and write decisions. The erase gate 𝒃t{\bm{b}}_{t} selects which key-side coordinates of the decayed state are read and removed, while the write gate 𝐰t\mathbf{w}_{t} selects which value-side coordinates are committed. This removes the scalar βt\beta_{t} tie in Gated DeltaNet and KDA, recovers both as special cases, and preserves efficient chunkwise training through a WY form with gate-aware kernels. Under matched 1.3B training, Gated DeltaNet-2 improves the recurrent and hybrid frontier across language modeling, commonsense reasoning, synthetic retrieval, and real-world recall, while adding only a small constant throughput overhead. Ablations show that both gates contribute, with the erase gate accounting for most of the gain.

D.1 衰减精度 D.1 Decay precision

式 86 中的衰减门在进入核之前以显式 fp32 计算。这一点很重要，因为局部累积和 𝑮r=∑i≤r𝒈i\bm{G}_{r}=\sum_{i\leq r}\bm{g}_{i} 是一个依赖于路径长度的量。低精度尾数可能会扰动长衰减乘积，即使每个词元门很小。因此，核接收对数衰减张量，并仅计算局部累积和与指数。

The decay gate in Eq. 86 is computed in explicit fp32 before entering the kernels. This is important because the local cumulative sum 𝑮r=∑i≤r𝒈i\bm{G}_{r}=\sum_{i\leq r}\bm{g}_{i} is a path-length-dependent quantity. A low precision mantissa can perturb long products of decays even when each tokenwise gate is small. The kernels therefore receive the log-decay tensor and only compute local cumulative sums and exponentials.

The triangular solve for 𝐀=(𝐈+𝐓)−1{\mathbf{A}}=({\mathbf{I}}+{\mathbf{T}})^{-1} is the most precision-sensitive part of the chunk computation. The conservative IEEE fp32 path is used when required by the hardware check, while the remaining matrix products can use the faster tensor-core path.

Unless stated otherwise, all models have 1.3B parameters and are trained on 100B tokens sampled from FineWeb-Edu [26]. We use AdamW with peak learning rate 4×10−44\times 10^{-4}, weight decay 0.10.1, and gradient clipping at 1.01.0. The learning rate follows cosine annealing with a 1B-token warm-up. The global batch size is 0.5M tokens. The training sequence length is 4K tokens. Hybrid models use a 2K SWA window.

我们采用预训练循环语言模型常用的评估套件 [41]。语言建模质量通过 WikiText [Wiki. 27] 和 LAMBADA [LMB. 28] 上的困惑度来衡量。对于零样本迁移，我们报告 LAMBADA 准确率以及 PIQA [29]、HellaSwag [Hella. 30]、WinoGrande [Wino. 31]、ARC-Easy 和 ARC-Challenge [ARC-e 和 ARC-c 32]、OpenBookQA [OBQA 33]、Social IQa [SIQA 34] 和 BoolQ [35]。这一组合涵盖下一个词预测、物理和社会推理、常识补全以及基础科学问答。

We use the evaluation suite commonly adopted for pretrained recurrent language models [41]. Language modeling quality is measured by perplexity on WikiText [Wiki. 27] and LAMBADA [LMB. 28]. For zero-shot transfer, we report LAMBADA accuracy together with PIQA [29], HellaSwag [Hella. 30], WinoGrande [Wino. 31], ARC-Easy and ARC-Challenge [ARC-e and ARC-c 32], OpenBookQA [OBQA 33], Social IQa [SIQA 34], and BoolQ [35]. This mix covers next-token prediction, physical and social reasoning, commonsense completion, and elementary science QA.

我们在受控合成设置和真实数据设置中评估检索。对于合成检索，我们使用 RULER [36] 中的单针大海捞针（S-NIAH）和多键大海捞针（MK-NIAH）任务。S-NIAH 套件包含三个逐渐变难的案例。S-NIAH-1 是密码检索，S-NIAH-2 要求检索数字针，S-NIAH-3 要求检索基于词的针。我们还评估了 MK-NIAH-1，其中存在多个干扰键值对，模型必须返回与一个请求键关联的值。

We evaluate retrieval in both controlled synthetic settings and real-data settings. For synthetic retrieval, we use Single Needle-In-A-Haystack (S-NIAH) and Multi-Key Needle-In-A-Haystack (MK-NIAH) tasks from RULER [36]. The S-NIAH suite contains three progressively harder cases. S-NIAH-1 is passkey retrieval, S-NIAH-2 asks for a numerical needle, and S-NIAH-3 asks for a word-based needle. We additionally evaluate MK-NIAH-1 where several distractor key-value pairs are present and the model must return the value associated with one requested key.

对于真实世界检索，我们遵循 [37]。该套件包括用于从 HTML 中提取结构化关系的 SWDE [46]、用于从 PDF 中检索键值对的 FDA [47]，以及问答数据集，包括 SQuAD [48]、TriviaQA [49]、DROP [50] 和 Natural Questions [51]。

For real-world retrieval, we follow [37]. The suite includes SWDE [46] for structured relation extraction from HTML, FDA [47] for key-value retrieval from PDFs, and question-answering datasets including SQuAD [48], TriviaQA [49], DROP [50], and Natural Questions [51].
